 1️⃣ What is the difference between var, let, and const?
 Answer:var, let, and const declares variables in JavaScript.

The main differences are:

1. var is function scoped. But let and const are block scoped.
2. var can be redeclared and updated, and let can be updated but cannot be redeclared in the same scope.
3. While const cannot be updated or redeclared after declaration.

2️⃣ What is the spread operator (...)?
Answer:
The spread operator (...) helps to expand elements of an array or object. Additionally, it helps to copy or merge arrays and objects easily.

3️⃣ What is the difference between map(), filter(), and forEach()?
Answer: 
map(), filter(), and forEach() works with arrays.

1. map() creates a new array and apply a function to each element.
2. filter() creates a new array with elements, which match a condition.
3. forEach() loops through the array, doesn't return anything.

Answer:
An arrow function is a modern shorter way to write a function in JavaScript. Arrow functions can be written in different variations. These functions make the code cleaner and easier to read.

5️⃣ What are template literals?
Answer:
Template literals is a modern way to works with strings in JavaScript. These are used to create strings using backticks (` `). They allow us to include variables inside strings using ${}. This makes string formatting easier and more readable. There are 4 types of literals.
